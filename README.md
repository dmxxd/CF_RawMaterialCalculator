# ComfortFurniture — расчёт сырья

Репозиторий содержит метод расчёта количества сырья, необходимого для производства мебельной продукции, с учётом процента отходов.

## Метод

`CalculateRawMaterial(int productTypeId, int materialTypeId, int quantity, double parameter1, double parameter2)`

### Параметры
- `productTypeId` — идентификатор типа продукции.
- `materialTypeId` — идентификатор типа материала.
- `quantity` — количество изделий.
- `parameter1` — первый параметр изделия.
- `parameter2` — второй параметр изделия.

### Результат
Метод возвращает целое число — необходимое количество сырья с учётом отходов, округлённое вверх.

Если переданы некорректные данные или не удалось выполнить расчёт, метод возвращает `-1`.

## Формула расчёта

Количество сырья рассчитывается по формуле:

`Q = quantity × parameter1 × parameter2 × coefficient / (1 - lossPercent)`

Где:
- `coefficient` — коэффициент типа продукции из базы данных.
- `lossPercent` — доля отходов материала из базы данных.

## Зависимости

Для получения коэффициента продукции и процента отходов используется класс `Db` основного приложения ComfortFurniture, подключённый к базе данных MySQL.

Файл с реализацией метода: `RawMaterialCalculator.cs`.
